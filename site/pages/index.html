Fossel is a local-first MCP memory server. It keeps your repo's conventions, bug fixes and decisions in SQLite on your machine, and serves them back to Cursor, Claude and any stdio MCP client.

Try it

Run the onboarding command inside a repository. It prints the MCP config to paste into your client and adds a starter memory if the database is empty.

npx -y fossel init

The database lives at ~/.fossel/memory.db. Set FOSSEL_DB_PATH to put it somewhere else.
