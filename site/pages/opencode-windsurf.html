OpenCode and Windsurf both launch Fossel as a local stdio server. OpenCode takes the command as an array, Windsurf as command plus args.

OpenCode

Tested with OpenCode 1.14.48: the config below connected, and opencode mcp list showed Fossel as connected. OpenCode's config format has changed between versions, so read the version note.

Create opencode.json in your project root, or use the global config at ~/.config/opencode/opencode.json:

{ "$schema": "https://opencode.ai/config.json", "mcp": { "fossel": { "type": "local", "command": ["npx", "-y", "fossel"], "enabled": true } } }

OpenCode starts the server in the project folder, so Fossel finds the right repo without FOSSEL_WORKSPACE. This was confirmed by having OpenCode launch a probe command and reading the working directory it received.

Verify

opencode mcp list

The output shows fossel with a check mark and connected. Then ask the agent to call resolve_repo, and try remember: Fossel is working in this repo.

Version note

OpenCode's current online documentation describes a newer layout with servers under mcp.servers. OpenCode 1.14.48 rejected that layout with a configuration error and accepted servers directly under mcp, as above. If opencode mcp list reports a configuration error, check your version with opencode --version and use the layout that version's documentation shows. The command array stays ["npx", "-y", "fossel"] either way.

Windsurf

Not tested here: Windsurf was not installed on the machine that wrote this page. This section follows the Windsurf Cascade MCP docs, and Fossel's side is checked against the source.

In Cascade, open the ... menu, choose Open MCP config file in the MCPs section, and merge this entry into mcpServers:

{ "mcpServers": { "fossel": { "command": "npx", "args": ["-y", "fossel"], "env": { "FOSSEL_WORKSPACE": "/absolute/path/to/project" } } } }

Use an absolute project path. Cascade documents ${env:VAR_NAME} and ${file:/path/to/file} interpolation, but not Cursor's ${workspaceFolder}.

Verify

Refresh the MCP list in Cascade and confirm fossel and its tools appear. Then ask the agent to call resolve_repo and check that the repo key matches your project.
